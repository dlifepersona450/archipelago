# Showcase captures

[README proyek](../../README.md) · [Docs](../README.md) · [Asal aset](../../ASSET_SOURCES.md)

Gambar pada folder ini adalah screenshot dari aplikasi lokal ARCHIPELAGO, bukan concept art atau capture situs referensi. Capture dibuat pada 22 Oktober 2026 dengan Chromium/Chrome headless, font lokal selesai dimuat, dan preferensi reduced motion untuk kondisi kamera yang stabil.

| Gambar                        | Kondisi                                                                 |
| ----------------------------- | ----------------------------------------------------------------------- |
| [Desktop atlas](desktop.png)  | 1440 × 1050, empat pulau prosedural dan navigasi HTML                   |
| [Quick View](quick-view.png)  | 1440 × 1050, daftar proyek yang menggunakan record yang sama            |
| [Beyond the Frame](depth.png) | Modal dengan ilustrasi tiga lapis; motion dikurangi agar capture stabil |
| [Fluid Lens](fluid-lens.png)  | Modal shader dengan kontrol material; bukan simulasi fluida fisik       |
| [Mobile](mobile.png)          | 390 × 844, peta CSS ringan dan jalur navigasi yang setara               |

Untuk memperbarui capture: jalankan dev/preview server, buka view yang disebutkan, tunggu font dan canvas selesai, lalu screenshot viewport atau dialog. Untuk depth dengan layer terbuka, aktifkan motion secara sadar dan tunggu transisi; jelaskan perubahan kondisi capture. Jangan menyajikan screenshot mode reduced sebagai bukti motion visual.

Screenshot docs tidak disertakan pada bundle aplikasi. Software WebGL rendering dapat berbeda sedikit dari GPU perangkat nyata. Capture ini bukan bukti seluruh browser telah diuji atau bahwa konten sample merupakan proyek klien yang nyata.
