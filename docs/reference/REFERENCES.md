# Referensi desain dan teknis

[Docs](../README.md) · [Assets](../../ASSET_SOURCES.md)

Ditinjau untuk fondasi proyek pada **22 Oktober 2026**. Referensi teknis berikut adalah sumber primer. API docs upstream dapat mengikuti versi terbaru; implementation source dan lockfile proyek menentukan versi yang sebenarnya dipakai.

| [React Three Fiber: scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance)                                                        | Prinsip demand rendering/invalidation; proyek memakai Three.js langsung dan tidak mengklaim memakai React Three Fiber |
