# Hak dan penggunaan ulang

[Docs](../README.md) · [Asset register](../../ASSET_SOURCES.md) · [Notices](../../THIRD_PARTY_NOTICES.md)

Source proyek, copy, dan ilustrasi dibuat untuk prototype ini, tetapi lisensi keseluruhan belum dipilih pemilik. Jangan mengasumsikan MIT berlaku ke semua file hanya karena Three.js memakai MIT. Notice OFL berlaku pada font masing-masing.

Sebelum menambahkan asset pihak ketiga, catat creator/source, izin penggunaan dan redistribusi, attribution yang wajib, modifikasi, dan lokasi notice. Reference link atau inspirasi tidak memberikan izin menyalin model, screenshot, source shader, foto, atau desain karakter.

Foto pribadi dapat memerlukan pertimbangan izin orang yang terlihat, publikasi lokasi/EXIF, dan konten privat. Pilih aset yang memang boleh dibuka publik; proyek tidak otomatis membersihkan metadata atau memeriksa hak aset.

Screenshot dalam showcase menggambarkan aplikasi lokal dan mengikuti notices materi yang terlihat. Capture tidak mengubah status lisensi source atau memberi izin tambahan atas font pihak ketiga.
